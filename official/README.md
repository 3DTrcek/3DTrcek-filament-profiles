# Official 3DTrcek profiles

Tuned and tested by the 3DTrcek team on our own printers.

| Folder | Printers |
|---|---|
| [`bambu-lab/H2S`](bambu-lab/H2S) | Bambu Lab H2S |
| [`bambu-lab/X1-P1`](bambu-lab/X1-P1) | Bambu Lab X1, X1C, P1S, P1P |

File naming: `3DTrcek_<Material>_<Printer>_<Nozzle>.json` — e.g. `3DTrcek_PETG-Mat_H2S_0.4.json`.

Found something that works better? Open an issue and tell us what you changed — we'll test it and update the official profile.
