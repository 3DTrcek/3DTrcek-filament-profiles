# Community profiles

Shared by 3DTrcek users for printers we don't run in-house. Each profile was tested by the person who submitted it — read the notes in the pull request or issue linked from the commit history for their setup.

Folders: `<brand>/<model>/`. Missing your printer? [Submit a profile](../CONTRIBUTING.md) and create the folder.

File naming: `3DTrcek_<Material>_<Printer>_<Nozzle>_by-<Name>.json`
